> Quickstart

Get your key and send a request in 3 steps.

# Step 1: Sign up & get your API key
# Go to https://synthropy.gg/signup

# Step 2: List available models
curl https://api.synthropy.gg/v1/models

# Step 3: Send a message
curl https://api.synthropy.gg/v1/chat/completions \
  -H "Authorization: Bearer sk-syn-xxx" \
  -d '{"model":"deepseek-ai/DeepSeek-V4-Flash-0731","messages":[{"role":"user","content":"hello"}]}'

> Authentication

All requests require a Bearer token in the Authorization header.

curl https://api.synthropy.gg/v1/chat/completions \
  -H "Authorization: Bearer sk-syn-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-ai/DeepSeek-V4-Flash-0731","messages":[{"role":"user","content":"hello"}]}'
Keys are tied to your account. 50M free tokens on signup. Track usage from the dashboard.

> API Reference

Base URL: https://api.synthropy.gg/v1

POST /v1/chat/completions

ParameterTypeDescription
modelstringModel ID from /v1/models
messagesarrayMessage objects with role + content
temperaturenumber0.0 - 2.0 (default 0.7)
max_tokensintMax tokens (default 250000)
streamboolStreaming response (default false)

Response

# Response format
{"id":"chatcmpl-x","object":"chat.completion",
  "choices":[{"message":{"role":"assistant","content":"Hello!"}}],
  "usage":{"prompt_tokens":10,"completion_tokens":5,"total_tokens":15}}
